# Raw data

Place the raw dataset here as `mudah-apartment-kl-selangor.csv`.

This CSV (scraped apartment/condo rental listings for Kuala Lumpur and
Selangor from mudah.my) is not committed to the repository. It's listed in
`.gitignore` so the repo stays lightweight and doesn't redistribute scraped
data. Source it yourself (e.g. from Kaggle) and drop it in this folder before
running `src/train.py`.
